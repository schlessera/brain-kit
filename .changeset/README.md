# Changesets

This directory holds release notes consumed by
[`@changesets/cli`](https://github.com/changesets/changesets). Run
`bun run changeset` when a change should ship, then use `bun run version` and
`bun run release` for the release workflow.

The eight `@endoxa/*` packages are configured as a fixed group so they remain
on one lockstep version.
