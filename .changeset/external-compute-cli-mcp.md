Expose external compute through `brain compute` and the `brain_compute_*` MCP tools (#3107). `brain compute health|plan|run|status|cancel|collect` and the operator verbs `reconcile` and `abandon --confirm` print the same JSON envelopes as the six new MCP tools, which call one core operation set: `{ ok: true, ... }`, or `{ ok: false, error: { code, message } }` with a stable refusal code and nothing allocated. `run` names its instance with `--provider` (no default), declares its uploads with `--source`, its artifacts with `--artifact` and non-secret variables with `--env`, and stays attached until the job ends and its cleanup settles: Ctrl-C cancels it, even while it is still starting, and reports whether the sandbox was released, a job whose cleanup is not confirmed exits 2 and points at `brain compute reconcile`, and `--detach` returns once it has started. Job views report the instance, source hash, state, exit, cleanup fact and cost, with unknown cost as `null`. The MCP tools are registered whatever the config says, take strict inputs with no caller fields, and the server keeps advancing the jobs it started. A new `external-compute` skill guides agents to run cheap work locally and to finish every job.
