Adds the internal entry point `@schlessera/brain-common/internal/google-operations` (#4203), the pure foundation the Gmail host tools build on. It defines the ten Gmail operation ids and the six `brain_google_gmail_*` tool names, each operation's base effect class (`read`, `reversible` or `irreversible`) and approval entity, strict input schemas with a `structured` or `content` view and Gmail id shapes, limits and error codes. `classifyGoogleCall` computes a call's effect class from its validated input and host-supplied facts: it only escalates, and an unknown operation, a refused input or a missing fact is irreversible. A strict mailbox parser and `matchesAllowList` compare addresses by addr-spec only, refusing group syntax, comments and quoted local parts, with domains in lower-case punycode and no subdomain match. A raw-draft parser reads the headers and plain-text body a send card shows, flags HTML parts, attachments and anything unreadable, and digests the exact bytes. Structured projections carry only validated ids, label names (a name longer than Gmail's 225 code points is dropped, never truncated, and the rest is escaped, so a projected name is at most 2,250 characters), timestamps, counts, size buckets, flags and host cursors. Within the packages, the `google` policy block and decision function (#4204), the gog transport (#4205) and the host's Google credential (#4206) build on it; no tool exposes it yet, and the names and schemas become contract when the host tools do (#4207).
