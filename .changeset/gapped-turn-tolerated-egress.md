A turn that began with a permanent safety recording gap no longer refuses its ordinary network traffic, or stops, when the writer tolerates a lost record (#4351). On such a turn the occurrence writer returns `{id:0, recorded:false}` by design, because the gap already shows the loss. An untrusted proxy connection now proceeds under the restricted recipient policy it already passed, without source trust, instead of refusing with 503 `egress_unavailable`. A lost terminal exposure no longer stops the turn. Such a turn raises no approval card and uses none it holds: a connection that would need a Network card (an ordinary destination or a managed GitHub fetch) or an outward card is refused without one, recorded with reason `recording_gap` and answered with a 403 naming it. The SDK proxy checks the gap before any approval callback and again at dispatch, so a card pending or answered when the gap appears is never used, and a managed GitHub fetch refused this way tells its caller to start a new turn. Allow-listed and already-contacted destinations still connect, and a new turn restores approvals. The SDK egress proxy takes the gap from a new `recordingGap()` option and asks a new synchronous `outwardCovered()` option first, so outward traffic that a call in progress already covers needs no card and still connects. The extraction classifier follows the same rule: on such a turn its `ask` verdict refuses the call without a card, its `allow` never counts a new host as contacted, and a call its card approved is refused before dispatch once a gap opens. A gap that cannot be read refuses card paths as `egress_unavailable` (503). Only the exact `{id:0, recorded:false}` acknowledgment counts as a tolerated loss; a positive id is a durable replay that keeps its evidence, and a `restricted_begin` other than 0 or 1 counts as unknown. Source-trusted connections still need a durable occurrence and refuse with 503 without one, and every other lost write, including a refused write such as a full recording queue, a lost connection audit or any loss on a turn without a permanent gap, keeps its existing containment.
