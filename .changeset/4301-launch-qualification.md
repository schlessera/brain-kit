Every worker launch with a caller-supplied command is now qualified against host private state before its payload starts (#4301). While the sandbox's start gate is still closed, the host reads the sandbox's own mount table and judges every existing state root its process registered (`registerWorkerPrivateState`): a root, a directory above one, or part of one that is live at a name the sandbox's UIDs can open refuses that launch with a `WorkerPrivateStateError` whose `reason` and `errorClass` are `private_state_exposed`. The error names the setting, the live name and the mount row, and is not a `WorkerHostError`; `privateStateRefusalOf` finds it through any `cause` chain. Owner-only state that the sandbox's UIDs do not own is reported and the launch runs. An unreadable, unfinished or ambiguous mount table refuses nothing by itself: the registered walk runs at the launch, and its own refusal is thrown with its reason. The launcher's fixed probes are not qualified.

The asynchronous direct-spawn maintenance and transport launches (`launchMaintenanceWorker`, `runMaintenanceWorker`) are qualified at their start gate like agent workers. Synchronous maintenance (`runMaintenanceWorkerSync`) is not qualified: it runs the brain's registered alias walk itself before it spawns (a warm admission walks each registered layout once; a retried, repeated or refreshed launch walks again) and refuses with the walk's typed reason, and every synchronous launch for a brain with a layout, or that masks, is recorded as unqualified (`unqualifiedLaunches`, site `synchronous-maintenance`); its sandbox is unchanged. Every qualified sandbox gains one read-only tmpfs at `/tmp/.brain-worker-seal`, mounted last, which marks a finished table.

Behaviour change: a host whose private state is reachable at an unmasked name, by a launch whose UID can open it, now has those launches refused until its layout is fixed. A launch for a brain with no registered layout (a backend or library used on its own) runs unqualified, as before; when it declares mask paths the skip is recorded (`unqualifiedLaunches`, `onUnqualifiedLaunch`), never silent. `GovernedUnavailableReason` and `FIRST_PARTY_FAILURE_CLASSES` gain `private_state_exposed` (additive).
