# Suggestions measurement, 2026-10-07

Issue #550 compares the shipped suggestions description with the same description minus its `suggestions:` line. Both arms keep the opening description sentence, schema variant, loaded roster and production brief unchanged. This is not a comparison with all suggestions wording removed.

Each instrument runs three repetitions of each of six prompts per arm, serially: SDK 36, Claude server 36 and Pi server 36. Rule precedes no-rule, so cache and time/order effects are confounded with the arm. Classification is off throughout. Every scored turn receives unchanged corpus bytes, a fresh fixture, and an empty native home/config. The observer disables Claude auto-memory and pins default/background/subagent model selectors to Sonnet 5.5.

The filesystem boundary protects the personal home; it still admits readonly public source/runtime and writable fictional scratch. Server outside-corpus exclusion is a retrospective tool-call heuristic rather than a proof of corpus-only access. The description and runtime preloads are measurement-only, and production handlers and schemas are unchanged.

Only completed turns with accepted, parsed suggestions calls count in the rate. All accepted calls contribute emitted-item/drop denominators; only the final accepted call contributes kept-item quality samples. Actual question endings and question-prompt controls have separate denominators. Empty normalized labels, duplicates, repeated prompts and filler are dropped in client order. Question-ending row suppression is separate from those item drops. Every final-call kept item is reviewed against its answer; an empty denominator is not measured.

The successful complementary review used native Claude CLI 2.1.292. SDK scored turns used the Agent SDK 0.3.283 bundled CLI 2.1.283; the server selects native CLI 2.1.292. The older bundled CLI returned fallback SDK price/context metadata, so costs use independently derived raw token usage and official Sonnet 5.5 rates rather than its fallback dollar number. Pi uses its exact built-in Sonnet 5.5 catalog entry. Its first OAuth-environment request was rejected HTTP 400 as out of extra usage, with no answer and no trustworthy billed-charge receipt. The standing authorization permits the Anthropic API key when Pi cannot use the subscription. All 36 scored Pi cells use fresh API-key requests, with OAuth removed from environment and empty runtime auth/config; no scored OAuth result is pooled. The API transport uniformly selects standard-only capacity and global geography, preserving prompt/schema/model/effort/output limits. Requested and served metadata is recorded separately. No model is silently substituted.

Subscription route receipts require an isolated OAuth environment, raw init `apiKeySource: none`, first-party initialization account selector and only the named model in `modelUsage`. The stdout observer forwards bytes unchanged, parses streaming UTF-8 and EOF without a newline, and retains native results even when the SDK throws. Unknown/new error/auth/model/overage receipts stop dispatch.

The maintainer cap ruling applies to actual additional billed charges: $15 for this issue within $150 aggregate. API-price equivalents are separate diagnostics. Historic Sonnet 5 failed-review usage and its unobserved overage receipt remain unknown; they are not pooled with fresh 5.5 results. Two server loader failures occurred before any native start and are recorded separately. Official rates per million tokens are input 2, output 10, cache read 0.20, cache write 2.50(5 m) or 4(1 h). Missing write TTL produces a price interval. Before every physical Pi API request, the guard reserves at most 5.28 USD:1 M input tokens at worst 1 h cache-write 4/M plus 128 k output tokens at 10/M. It refuses a request when accumulated API usage-charge upper plus that request reservation would exceed 15 USD. Incomplete/error receipts retain an unknown charge and stop future cells; an HTTP failure’s default zero SDK counters are never an invoice proof. Sonnet 5.5 is excluded from Priority Tier by the current service-tiers reference; explicit standard/global selectors make the billing protocol auditable. Request metadata pins only those billing fields, not generation settings.

Offline native controls exercised real server descriptor require/bootstrap, native initialization/settings/chat/result, EOF/error receipt capture, and Brain CLI/MCP list/read with the exact fixture-local wrapper and readonly core source alias. They sent no provider request. Deliberately split UTF-8 and API-key/missing-init/account controls cover transport and auth rejection. A client-counter mutation proved the empty-normalized-label assertion fails when its guard is removed.

Execution source hashes and approved review receipts are retained separately from parameterized reproduction files; parameterization changes local paths and must not be described as an exact-byte replay of the measured host manifest.

SDK turns do not expose terminal stream deltas; native per-request usage remains unclaimed rather than being inferred from assistant frames. Pi’s 91 physical receipts use final provider deltas.
