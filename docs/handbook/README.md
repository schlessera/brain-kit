# The brain-kit handbook

A brain is a collection of notes, plans and decisions that you own. Brain-kit
helps you find those records, connect them and work on them with an agent.
The files stay readable even when you change tools.

This handbook takes you from that idea to a useful everyday workflow. You can
start with capture and keyword search, then add an agent, domain workflows or
a rich interface when you need them.

## Start here

- [How your brain works](concepts.md) — understand the files, their metadata
  and the connections between them.
- [Create your first brain](quickstart.md) — make your own private repository,
  capture a note and find it again.

Read these two chapters first. You do not need a model account to complete
the first capture and search.

## Everyday use

- [Capture and find](daily-workflow.md) — keep a thought, retrieve it and use
  the context you find.
- [Organize and review](organizing.md) — give notes a useful home without
  turning maintenance into a second job.
- [Work with an agent](agents.md) — move from finding information to making
  decisions and updating your files.
- [Use the rich interface](interface.md) — understand structured answers,
  file previews, approvals and voice capture.

If you already have a brain, start with the everyday task you want to improve.

## Make it yours

- [Search by words and meaning](search.md) — choose when ordinary keyword
  search is enough and when semantic search helps.
- [Configure your brain](configuration.md) — change a few settings as your
  needs grow.
- [Add domain workflows](modules.md) — bring in a module for a particular
  kind of work.
- [Back up and sync](hosting.md) — keep an off-machine copy and understand
  what optional hosting adds.

These capabilities are optional. Add them to solve a problem you have already
met rather than configuring everything at once.

## Build integrations

- [Build with brain-kit](extending.md) — find the public packages and extension
  interfaces when you are ready to build an integration or your own UI.

Detailed command and API references live in the
[engineering documentation on GitHub](../README.md). They are available when
you need an exact flag, schema or implementation decision; they are not the
reading path through this handbook.
