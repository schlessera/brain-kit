The normal JetBrains Mono 400/600 and Plus Jakarta Sans
500/600 faces are byte-identical copies of the corresponding locked website
assets. Source URLs, SHA-256 checksums and upstream OFL license identities live
in `scripts/captures/font-lock.json`. The adjacent licenses accompany every
published copy. Exports inline these trusted bytes as data fonts; they never
fetch fonts or consult a user's filesystem for font content.
