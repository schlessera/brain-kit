# Loop

Use `positional.loop` with exactly one hub node and an ordered station list covering all remaining nodes. The last station returns to the first; a non-returning process belongs in a flowchart. Equal-angle clockwise station placement generates true same-radius circular arcs, while radial dashed write-backs point inward to accumulated state. These are the pinned Loop-specific exceptions to general orthogonal routing. Spoke labels are optional and use opaque masks with 8px clearance. Prefer 5–8 stations. Brain-kit adapts upstream’s hard editorial count to budget warnings, preserving legacy v1 forms; valid unique hub/reference structure remains mandatory. Returns use the adopted 6 4 dash, overriding upstream’s 5 4.
