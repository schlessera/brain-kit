# Layer stack

Use `positional.stack` for an optional exact node order and up/down direction label. Layers are equal full-width bands with consecutive L tags, names and optional sublabels. Prefer 4–6 layers. Focal emphasis uses one solid kit tint and stronger outline, with neutral bands carrying the hierarchy.

[Odysseus example](examples/positional/layer-stack.diagram.yaml), pinned to `2026-07-12`.

Adapted from diagram-design commit `b46c9701f035844a20b13ab0551315977188933b` under the module MIT notice. Brain-kit keeps its fonts, solid token paints, 9px floor and white print ground. The source spec remains authoritative; missing authored narrow placement selects the caption/summary and Open diagram viewer, never automatic reflow.

Legacy sources without the typed block stay valid with a positional interpretation warning. Input order defines equal qualitative layers.
