# Flywheel

Use the Loop grammar for a reinforcing operating flywheel with one shared accumulating hub. Ring order is semantic, clockwise and cyclic; spokes represent write-back and never a second operating ring. `positional.loop.spokeLabels` references stations and labels only selected write-backs. Prefer 5–8 stations, one focal station at most, and concise hub copy. See loop.md for the circular/radial construction and count adaptation.
