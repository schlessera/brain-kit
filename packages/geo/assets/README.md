# Bundled map fonts

Unmodified IBM Plex Sans Regular and Medium, from IBM's public
[Plex repository](https://github.com/IBM/plex) at commit
`763c36ef9117782905ae010056dfbe8fd2653a25`:

- `packages/plex-sans/fonts/complete/ttf/IBMPlexSans-Regular.ttf`
- `packages/plex-sans/fonts/complete/ttf/IBMPlexSans-Medium.ttf`

The accompanying [OFL.txt](OFL.txt) carries the original license text, allowing
redistribution/embedding; line endings and trailing whitespace are normalized.
Fontkit measures and turns glyphs into vector outlines;
resvg renders only local generated geometry with system fonts disabled. No font
or raster image is fetched when making a map. The font license remains separate
from geo's MIT code and from OSM-derived data/artifact attribution.
